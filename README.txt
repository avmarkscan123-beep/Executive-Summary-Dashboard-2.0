SOURCE DATA FOR IP HOUSE DASHBOARD

Replace this folder's dashboard-data.xlsx with your latest source Excel file.

GitHub Pages workflow:
1. Keep index.html and this data folder in the repository.
2. Upload your Excel as: data/dashboard-data.xlsx
3. Open/refresh the GitHub Pages dashboard.
4. The dashboard automatically loads the Excel; clients do not upload anything.
5. Clients can use the Download Source Excel button to download the same file.

The Excel must have its headers in the first row and data on the first sheet.
